# Orison Project — Coming Soon

A responsive, single-page coming-soon website built with plain HTML and CSS.

## Files
- `index.html` — page content and metadata
- `style.css` — responsive layout and styling
- `mark.png` — supplied brand artwork

## Run locally
Open `index.html` in a browser. No build tools, package manager, or dependencies are required.

## Deploy
This is a static site. Import the repository into Vercel and use the repository root as the project root. No build command is required; the site can be served as static HTML. It can also be hosted on GitHub Pages or Netlify.

## Project description
The Orison Project applies machine learning and economic modeling to dismantle structural poverty and drive economic mobility. Its areas of focus include applied AI research, development economics, data analytics, monitoring and evaluation, AI safety and governance, global health, animal welfare, poverty alleviation, randomized controlled trials (RCTs), and mechanism design. The project aims to connect rigorous research with practical pathways toward human flourishing and economic equity.
